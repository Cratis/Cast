# @cratis/create-cast

Creates a [Cratis Cast](https://cast.cratis.io) site from your public GitHub profile.

```sh
npm create @cratis/cast@latest my-site -- --github your-login
```

Options: `[directory]`, `--github <login>`, `--domain <domain>`, `--yes`, `--help`. See [getting started](https://github.com/Cratis/Cast/blob/main/Documentation/getting-started.md).
